# Android／iOS 基本人工測試流程

## 使用前安全提醒

啟用輔助工具前先確認裝置的關閉方式與手勢。測試人員應使用測試帳號與測試資料，不要在錄影或截圖中暴露密碼、權杖、個人資料或真實付款資訊。

## Android：TalkBack 基本流程

1. 確認 Android 版本、裝置型號、App 版本、字級與顯示大小。
2. 啟用 TalkBack，先確認如何使用音量鍵捷徑或系統設定關閉。
3. 以線性瀏覽逐項檢查：頁面標題、按鈕名稱、圖片替代文字、輸入欄位標籤、狀態、錯誤與焦點順序。
4. 以探索觸控檢查元件是否有可操作名稱，並確認可互動區域不會被誤判為多個元素。
5. 以手勢完成核心流程：開啟頁面、搜尋、輸入、送出、取消、返回、切換、展開、關閉彈窗與完成結果。
6. 觸發載入、成功、錯誤、權限拒絕、網路中斷與重新連線，確認訊息會被讀取且不會把焦點送到不可預期的位置。
7. 改變字級、顯示大小、方向與高對比／色彩設定，重新執行核心流程。
8. 將結果記錄為通過、不通過、不適用或待確認，並保存螢幕錄影或截圖證據。

## iOS：VoiceOver 基本流程

1. 確認 iOS 版本、裝置型號、App 版本、文字大小、粗體文字與顯示設定。
2. 啟用 VoiceOver，先確認如何以三指點按或設定方式關閉。
3. 以左右滑動檢查元件順序、名稱、角色、提示、狀態與可執行動作。
4. 以轉子或適當導覽方式檢查標題、連結、表單控制項與文字區塊是否可快速瀏覽。
5. 以單指點按、雙指啟動、拖曳、調整值、輸入與返回完成核心流程。
6. 測試彈窗、頁面切換、鍵盤出現／收起、載入、錯誤、成功、權限拒絕與網路中斷。
7. 改變文字大小、粗體文字、增加對比、減少動態效果、方向與縮放設定，重新執行核心流程。
8. 記錄 VoiceOver 實際讀取文字與操作結果，不要只依視覺畫面推斷通過。

## 行動網站／Web App 額外流程

1. 使用行動瀏覽器確認縮放、文字重排、直向／橫向與瀏覽器返回行為。
2. 使用鍵盤或外接鍵盤檢查焦點順序、焦點可見性、跳至主要內容與表單錯誤關聯。
3. 使用瀏覽器輔助功能或平台螢幕閱讀器檢查標題階層、landmark、ARIA 名稱／角色／狀態與動態訊息。
4. 確認固定頂列、底列、Cookie 提示、聊天元件與彈窗不會遮蔽焦點或主要內容。

## 證據與判定規則

| 情況 | 判定方式 |
|---|---|
| 只看得到視覺畫面 | 只能做視覺初判；讀屏、焦點與動態狀態標為待確認 |
| 有原始碼但沒有實機 | 可指出語意與屬性風險；不能宣稱平台測試通過 |
| 有完整操作錄影與裝置資訊 | 可依錄影判斷可見操作；若沒有讀屏音訊，讀屏結果仍待確認 |
| TalkBack／VoiceOver 實機測試可重現 | 可記錄實際通過或不通過，附裝置、OS、版本與步驟 |
| 只在一台裝置測試 | 結論限制為該裝置／OS；平台相容性項目仍可能待確認 |

# 台灣行動 App AA 工作化檢核清單（第一版）

> 本清單是將官方行動版無障礙文件工作化的第一版，不取代主管機關最新檢核表。正式認證前，應逐項對照最新官方版本。

每項結果使用：通過／不通過／不適用／待確認。證據至少記錄畫面或流程、裝置／OS、輔助功能設定、操作步驟與觀察結果。

## 原則一：可感知

| 編號 | 檢核項目 | 測試重點 | 常見修正方向 |
|---|---|---|---|
| AA-01 | 非文字內容有文字替代 | 圖片、圖示、功能按鈕是否有適當名稱；純裝飾是否被略過 | 提供替代文字或 accessibility label，裝飾元素標為不需朗讀 |
| AA-02 | 時序媒體有替代方案 | 影片或音訊的重要資訊是否有文字或其他替代 | 提供逐字稿、音訊描述或等價文字內容 |
| AA-03 | 影片具字幕 | 語音內容是否能以字幕取得 | 提供同步、可讀且不遮蔽重要資訊的字幕 |
| AA-04 | 內容結構可被辨識 | 標題、區塊、清單、表格與群組是否有語意 | 使用原生語意或正確 accessibility role |
| AA-05 | 顏色不是唯一辨識方式 | 錯誤、狀態、分類是否只靠顏色區分 | 加入文字、圖示、圖案或狀態名稱 |
| AA-06 | 文字與背景對比足夠 | 主要文字、提示、按鈕與狀態文字是否清楚 | 調整色彩、字重、背景或提供高對比模式 |
| AA-07 | 文字可放大且不遺失內容 | 放大文字或系統字級後是否裁切、重疊或無法操作 | 使用彈性排版、可換行容器與足夠高度 |
| AA-08 | 螢幕方向變更不造成資訊遺失 | 旋轉或不同方向下內容與操作是否仍可用 | 支援響應式版面或清楚說明必要限制 |
| AA-09 | 動態內容有等價呈現 | 輪播、動畫、圖表或 Canvas/SVG 是否提供文字或操作替代 | 提供資料表、摘要、停止控制與可朗讀狀態 |
| AA-10 | 視覺焦點與狀態清楚 | 選取、停用、載入、成功與錯誤狀態是否可辨識 | 加入文字狀態、明顯焦點與可被輔助技術讀取的狀態 |

## 原則二：可操作

| 編號 | 檢核項目 | 測試重點 | 常見修正方向 |
|---|---|---|---|
| AA-11 | 所有功能有替代輸入方式 | 不依賴單一觸控手勢、搖晃或拖曳才能完成 | 提供按鈕、鍵盤、輔助技術或其他等價操作 |
| AA-12 | 觸控目標足夠大且間距合理 | 小按鈕、相鄰控制項是否容易誤觸 | 增加可點擊區與間距，不只放大視覺圖示 |
| AA-13 | 手勢有單點或簡化操作 | 多指、路徑、長按等複雜手勢是否有替代 | 提供單點按鈕或系統標準操作 |
| AA-14 | 操作可取消或避免誤觸 | 滑動、拖曳、提交與刪除是否能取消或復原 | 延後提交、提供取消／復原與確認訊息 |
| AA-15 | 時間限制可調整 | 登入逾時、倒數、限時表單是否有延長或關閉 | 提供延長、暫停、重新驗證與清楚警告 |
| AA-16 | 動畫與自動播放可停止 | 閃爍、移動、輪播、影片是否干擾閱讀或操作 | 提供停止／暫停／隱藏控制，避免危險閃爍 |
| AA-17 | 導覽順序合理 | 螢幕閱讀器、鍵盤或外接輸入的順序是否符合視覺與操作邏輯 | 修正 accessibility traversal、focus order 或 DOM 順序 |
| AA-18 | 焦點不遺失 | 彈窗、頁面切換、動態更新後焦點是否位於合理位置 | 開啟時移入對話框，關閉後返回觸發元件，更新後提供可控焦點 |
| AA-19 | 焦點可見且不被遮住 | 鍵盤或輔助技術焦點是否清楚、未被固定列遮蓋 | 提供高辨識焦點樣式與 scroll into view |
| AA-20 | 導覽位置與返回行為可預期 | 返回、麵包屑、分頁、底部導覽是否一致 | 維持平台慣例、正確更新頁面標題與歷史狀態 |
| AA-21 | 頁面或流程有跳過機制 | 長頁或重複導覽是否能快速到主要內容 | 提供跳至主要內容、標題導覽或區塊捷徑 |
| AA-22 | 避免造成癲癇或身體不適 | 閃爍、快速動畫、視差是否可關閉 | 降低頻率、尊重 reduced motion、提供靜態替代 |

## 原則三：可理解

| 編號 | 檢核項目 | 測試重點 | 常見修正方向 |
|---|---|---|---|
| AA-23 | 螢幕與元件語言可辨識 | 頁面語言與局部外語是否能被正確朗讀 | 設定語言屬性與正確發音資訊 |
| AA-24 | 元件名稱、角色、狀態完整 | 讀屏是否能得知按鈕／輸入框／選取器的用途與狀態 | 補齊 accessible name、role、value、state |
| AA-25 | 操作方式與介面一致 | 相同功能是否使用一致名稱、位置與行為 | 統一文案、元件樣式與操作模型 |
| AA-26 | 輸入欄位有標籤與說明 | 使用者是否知道要輸入什麼、格式為何 | 使用可朗讀標籤、提示、範例與輸入類型 |
| AA-27 | 輸入錯誤可辨識 | 錯誤是否與欄位關聯，讀屏是否能取得 | 提供文字錯誤、欄位關聯、錯誤位置與修正方法 |
| AA-28 | 錯誤預防與確認 | 付款、刪除、送出等重要操作是否可檢查與修正 | 提供摘要確認、編輯、取消與復原 |
| AA-29 | 動態訊息可被通知 | 成功、錯誤、載入完成、結果數量是否被輔助技術得知 | 使用 live region、accessibility announcement 或等價機制 |
| AA-30 | 說明文字簡潔可理解 | 指示、錯誤、權限與警告是否避免只用術語 | 使用清楚繁體中文、具體動詞與下一步指示 |
| AA-31 | 驗證碼有替代方式 | 圖形、聲音或互動驗證是否可由不同能力使用 | 提供替代驗證、重新取得與清楚錯誤訊息 |
| AA-32 | 權限與隱私提示可理解 | 相機、定位、聯絡人、通知等存取是否先說明用途 | 在系統提示前提供用途、選擇與拒絕後替代流程 |

## 原則四：穩健相容

| 編號 | 檢核項目 | 測試重點 | 常見修正方向 |
|---|---|---|---|
| AA-33 | 可與螢幕閱讀器相容 | TalkBack／VoiceOver 能瀏覽、朗讀與操作核心流程 | 使用平台標準元件、修正名稱／角色／狀態與順序 |
| AA-34 | 元件狀態會同步更新 | 展開、收合、選取、切換、進度與載入狀態是否正確回報 | 同步 accessibility state、value、expanded、selected 等資訊 |
| AA-35 | 自訂元件具完整語意 | 自訂滑桿、標籤、輪播、日期選擇器是否可被辨識 | 優先使用原生元件，否則補齊角色、操作與狀態 |
| AA-36 | 焦點與視覺內容同步 | 輔助技術目前項目是否與畫面可操作內容一致 | 避免隱藏元素仍可聚焦，更新可見性與順序 |
| AA-37 | 離線、慢速或中斷網路可理解 | 載入、逾時、重試、離線與同步狀態是否清楚 | 提供狀態文字、重試、取消與保留已輸入資料 |
| AA-38 | 瀏覽器或系統功能不被不當阻礙 | 返回、縮放、複製、分享、系統字級與輔助功能是否可用 | 不攔截標準行為，不以自訂機制取代必要系統功能 |
| AA-39 | 個人資料與本機儲存安全 | 密碼、權杖、個資與暫存資料是否以適當方式保護 | 避免明文儲存、縮小權限、提供登出與撤銷機制 |
| AA-40 | 資源使用不影響可用性 | 大圖、動畫、網路與處理器負載是否造成等待或失敗 | 壓縮資源、漸進載入、快取、離線策略與進度回饋 |
| AA-41 | 平台與裝置差異已測試 | 不同 OS、螢幕尺寸、字級、方向與輔助設定下是否仍可用 | 建立最低支援矩陣與代表性回歸測試 |
| AA-42 | 核心任務可完整完成 | 從啟動到完成任務是否沒有無障礙阻斷點 | 以真實任務做端到端測試，逐項修正並保留證據 |
